# 04 打点工作流（S1 探针）

> 定稿（2026-11-15）：只用一个工具，就是本地的**标注检查网页**。共享协作版和 Google Earth KML 两套流程已经停用并删除。

## 流程

```bash
conda activate tea2021
python stages/S1_probes/make_kit_<area>.py              # 候选点 → data/interim/S1/<kit>.csv
python stages/S1_probes/extract_timeseries.py <kit>     # GEE 提取 2021 年 S2 NDVI / S1 VH 时序
python stages/S1_probes/build_viewer.py <kit>           # → data/interim/S1/<kit>_viewer.html，双击打开
# 网页里标注 → "导出 CSV" → 原文件移到 data/raw/probes/exports/ 并登记 ledger
python stages/S1_probes/ingest.py data/raw/probes/exports/<导出>.csv --zone .. --area .. --province .. --annotator ..
python stages/S1_probes/check.py
```

## 网页标注

- 常用类别（第一排）：茶树 `t` · 非茶常绿林 `e` · 落叶林 `d` · 常绿落叶混交林 `m` · 耕地 `c` · 混合像元（不可用）`x`；其他类别在"更多类别"里。
- `1` `2` `3` 设置置信度（默认 3），`Enter` 跳到下一个，`↑` `↓` 切换。
- 标注暂存在浏览器里，换浏览器或清除数据会丢失，要经常导出备份；导出的 CSV 可以再"导入"恢复。

## 混合像元：挪到附近纯净像元

看到方框落在茶行与过道、林缘等交界处时，不必只标「混合像元」：

1. 按 <kbd>G</kbd>（或点「移动到纯净像元」），在地图上点一下附近纯净的位置，红点和 10 m 方框跟着移过去，原位置留灰圈。<kbd>Esc</kbd> 取消，「恢复原位」撤销。
2. 只在相邻几个像元内挪（超过 100 m 网页会提示）；挪不到纯净处就照旧标「混合像元」。
3. 移动后右侧曲线变淡：它仍是**原位置**的曲线，这时主要按影像判断。
4. 导出 CSV 里 lon/lat 是新位置，orig_lon/orig_lat/moved_m 记原位置和距离。
5. 有移动点时，入库前先复核：
   ```
   python stages/S1_probes/review_moved.py <kit> data/raw/probes/exports/<导出>.csv
   ```
   按新位置重新提取曲线，生成 `<kit>_moved_viewer.html`（预填 = 第一次标的标签）。复核完导出，入库时加 `--review <复核导出>.csv`。
6. 候选规则命中率按**原位置**统计，移动点单列。

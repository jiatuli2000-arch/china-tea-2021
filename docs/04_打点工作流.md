# 04 打点工作流（S1 探针 / S5 验证通用）

> 决定（2026-11-15）：**Google Earth 网页版**（核对 2021 年前后的高分历史影像）+ **自建时序辅助网页**（看 2021 年 Sentinel-2/1 时序曲线），两者结合。
> 更新（2026-11-15）：**标注直接在时序辅助网页里完成**并导出 CSV；Google Earth 只用来看历史影像。KML 流程保留为备用。

## 推荐流程：网页标注

```
python stages/S1_probes/extract_timeseries.py <kit>   # GEE 提取时序
python stages/S1_probes/build_viewer.py <kit>         # 生成 data/interim/S1/<kit>_viewer.html
→ 双击打开网页：点"在 Google Earth 网页版打开"看 2021 年影像 → 网页里按快捷键标注 → "导出 CSV"
python stages/S1_probes/ingest.py <导出.csv> --zone ... --area ... --province ... --annotator ...
```

快捷键：t 茶 · e 常绿林 · b 竹林 · d 落叶林 · o 果园 · c 农田 · s 灌草 · u 建筑 · w 水体 · a 古茶 · h 林下茶 · x 其他；1/2/3 置信度；Enter 下一个。
标注暂存在浏览器 localStorage 中，**换浏览器或清除数据会丢失**——经常导出；导出的 CSV 可以再"导入"恢复。

## 备用流程：Google Earth KML


```
脚本生成候选点 → 打点包 KML（每代表区一个，按 point_id 编号）
   → Google Earth 网页版：项目 → 导入 KML → 历史影像切到 2021 前后 → 逐点改名为标签代码
   → 疑难点：在时序辅助网页上看 NDVI / VH 曲线（常绿？修剪下凹？）
   → 导出 KML → 脚本转换为 data/raw/probes/<zone>.csv → S1 check
```

## 标注约定（在 Google Earth 里改地标名称）

`<point_id>|<label>|<confidence>`，例如 `JN0001|tea|3`

- `label` 取自 `docs/00` 的类别代码；`confidence` 取 1–3
- 核对所用影像日期写进地标描述，例如 `2021-03`

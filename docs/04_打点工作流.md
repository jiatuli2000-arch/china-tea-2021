# 04 打点工作流（S1 探针）

> 定稿（2026-11-15），2026-11-16 增加 Google Earth 复核：本地**打点工作台**（标注检查网页）负责打点，Google Earth 网页版负责复核，复核结果仍在本地网页里记录。共享协作版已停用。

## 固定流程：打点工作台 → Google Earth 复核 → 验收（2026-11-16 起）

每张探针表都要走完三步。只经过工作台的点**不能**用于下游。

```bash
conda activate tea2021
# ① 打点工作台
python stages/S1_probes/make_kit.py --kit <kit> --prefix .. --county .. --n tea=.. ...  # 盲标候选点
python stages/S1_probes/extract_timeseries.py <kit>
python stages/S1_probes/build_viewer.py <kit>            # → data/interim/S1/<kit>_viewer.html
# 网页标注 → 导出 CSV → 移到 data/raw/probes/exports/ 并登记 ledger
python stages/S1_probes/ingest.py data/raw/probes/exports/<导出>.csv --zone .. --area .. --province .. --annotator ..

# ② Google Earth 复核
python stages/S1_probes/make_ge_review.py <zone>__<area>   # → ge_<表>_viewer.html + ge_<表>.kml
# Google Earth 网页版：新建项目 → 导入 KML 文件 → 按左侧列表逐点看（可开历史影像）
# 复核网页同步：对 → Y；不对 → 按字母改标签；需要挪 → G
# 导出 CSV → 移到 data/raw/probes/exports/ 并登记 ledger
python stages/S1_probes/ingest_ge_review.py data/raw/probes/exports/<复核导出>.csv --table <zone>__<area> --reviewer ..

# ③ 验收
python stages/S1_probes/check.py
```

- 复核网页和 KML 的点顺序一致：先按标签（茶树、常绿林、落叶林……），再按点号。KML 每个类别一个文件夹、一种颜色，每个点带 10 m 方框。
- 复核网页的曲线按**当前坐标**重新提取，工作台里移动过的点在这一步才看到新位置的真实曲线。
- 复核结果另存 `data/raw/probes/review/<表>__ge.csv`，原探针表不改；`load_probes()` 合并时以复核为准，并保留 `label_workbench` 和 `verdict`（ok / changed），可以统计工作台阶段的出错率。
- 在 Google Earth 里看了某年历史影像，就在复核网页的「核对影像日期」里填上，入库时记为「Google Earth 历史影像」。

## 网页标注

- 常用类别（第一排）：茶树 `t` · 非茶常绿林 `e` · 落叶林 `d` · 常绿落叶混交林 `m` · 耕地 `c` · 混合像元（不可用）`x`；其他类别在"更多类别"里。
- `1` `2` `3` 设置置信度（默认 3），`Enter` 跳到下一个，`↑` `↓` 切换。
- 标注暂存在浏览器里，换浏览器或清除数据会丢失，要经常导出备份；导出的 CSV 可以再"导入"恢复。

## 判读依据（如实记录）

| 情形 | `imagery_source` | `imagery_date` |
|---|---|---|
| 默认：当前底图 + 2021 年时序曲线 | 当前影像 + 2021 年 Sentinel-2 时序 | `ts2021` |
| 另外看了 Google Earth 历史影像，并在网页上填了日期 | Google Earth 历史影像 | 所填日期 |

探针点按默认方式判读即可。**S5 独立验证点必须逐点核对 2021 年历史影像。**

## 混合像元：挪到附近纯净像元

看到方框落在茶行与过道、林缘等交界处时，不必只标「混合像元」：

1. 按 <kbd>G</kbd>（或点「移动到纯净像元」），在地图上点一下附近纯净的位置，红点和 10 m 方框跟着移过去，原位置留灰圈。<kbd>Esc</kbd> 取消，「恢复原位」撤销。
2. 只在相邻几个像元内挪（超过 100 m 网页会提示）；挪不到纯净处就照旧标「混合像元」。
3. 移动后右侧曲线变淡：它仍是**原位置**的曲线，这时主要按影像判断。
4. 导出 CSV 里 lon/lat 是新位置，orig_lon/orig_lat/moved_m 记原位置和距离。
5. 移动点在第 ② 步 Google Earth 复核时按新位置重新提取曲线，届时再确认。
6. 候选规则命中率按**原位置**统计，移动点单列。

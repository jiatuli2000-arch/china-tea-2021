# 05 杨高翔博士论文：方法逻辑解析与对茶树的启示

> 来源：`~/Zotero/storage/7NFSSK4E/杨高翔博士毕业论文.pdf`（印刷页码 = PDF 页码 − 24）。2026-11-16 通读第二至六章的方法、结果与讨论后整理。
> 标 [推测] 的是本项目的推断，不是原文结论。

## 1. 一句话总结

**先用农学知识造一个「目标类特有的指数」，让目标高、其他接近 0；再在每个局部格网里自动找阈值，给像素打初步标签；然后只从最可靠的像素里抽训练样本；最后用随机森林加多源特征出图。** 初步标签图本身不当作成果，它只是样本的来源（第六章 1.2，p.147）。

### 关键公式和数字

**AGTOC 规则**（p.27–28）：

| 类别 | 判别规则 |
|---|---|
| 水体 | NDVI_peak < 0 |
| 建筑 | 0 < NDVI_peak < 0.2 |
| 林地 | NDVI_harvest > 0.5，且 (peak − harvest)/peak < 0.2 |
| 冬季作物 | NDVI_peak > 0.5，且相对下降 > 0.4 |
| 油菜 | 用黄度变化指数 YCI 区分 |

**WCI**（式 3-2，p.54）：WCI = (NDVI_max − NDVI_min1) × (NDVI_max − NDVI_min2)
- 前一项是播种到抽穗的上升幅度，后一项是抽穗到收获的下降幅度，两者相乘。
- 冬季作物两项都大，WCI 大；林地、水体、建筑至少有一项接近 0，WCI 趋近 0。
- 结果是直方图呈双峰，Otsu 能直接切开。

**其他要点**：

| 内容 | 做法与数字 | 出处 |
|---|---|---|
| Otsu 的使用方式 | 每个 1°×1° 格网单独运行，以适应区域之间的光谱差异 | p.55 |
| 小麦与油菜区分 | 油菜开花后期 VH，阈值 −16 dB，用 11,734 个小麦像素和 11,675 个油菜像素确定 | p.57 |
| S1 预处理 | 只用升轨；**逐景 refined Lee 滤波**去相干斑；月度中值合成 | p.50 |
| S2 预处理 | 云概率掩膜；月度中值合成；缺失值线性插值（约 2% 像素） | p.49–50 |
| 验证样本 | 地面调查 + 按分层随机抽样目视解译 Google Earth；同样做 3×3 空间滤波 | p.51 |

## 3. 内在逻辑：八条设计原则

1. **知识造指数，不靠数据堆**。WCI 抓的是冬季作物「先升后降都很大」这一本质特征，用乘法同时放大目标、压低其他类。指数设计的目标是让直方图出现双峰。
2. **阈值局部自适应**。阈值不在全国统一，而是每个 1° 格网由 Otsu 自己找。前提是每个格网里目标和背景都要有足够的数量，否则直方图不是双峰，Otsu 会失效。
3. **由易到难、逐层剥离**。先分出非植被，再分出林地，最后处理最像的混淆类（油菜），而且为它单独找最敏感的特征和时期。AGTOC 先在收获期提取林地也是同样的思路。
4. **纯度优先于数量**。具体做法：耕地掩膜；对象内全部像素满足规则；只取中心像素；3×3 八邻域同类；没有可靠影像的区域宁可不出样本。
5. **样本不是成果**。规则只用来产生训练样本，最终图由 RF 加多源特征生成。理由有三：RF 对 20–25% 的标签噪声不敏感，精度只下降约 3%（p.147）；机器学习学到的是类别整体分布；样本区域有缺失时，最终图仍然完整。
6. **回避不稳定的物候窗口**。小麦的越冬期特征时空变异大，所以不使用（p.73）。只用阶段内的局部极值，例如 min1、max、min2，而不是某个固定日期的值。
7. **验证完全独立**。验证样本来自地面调查和分层目视解译，同样做纯度过滤；另外用统计数据检验面积一致性，但只作对照。
8. **两类先验知识**。第二、三、五章用直接先验（农学规律），第四章用间接先验（已有产品）。作者认为直接先验的时空拓展性更强（p.146）。

## 4. 对茶树的启示（本项目）

| 杨的做法 | 茶树的对应 | 风险或差别 [推测] |
|---|---|---|
| WCI：目标特有的乘积指数 | TI = 常绿度 × 管理扰动 × 矮度（S0 设想） | 现有证据：茶树与常绿林主要靠**夏季 NDVI 偏低**区分（AUC：黄山 0.90，安溪 0.82）；冬季 NDVI 无区分力；VH 骤降不是茶树特有（E03、E03c）。TI 的「扰动」分量还没找到可靠的信号 |
| 每个 1° 格网做 Otsu | 同样需要自适应阈值 | **最大差别**：冬小麦在许多格网里占比很高，直方图是双峰；茶园在绝大多数 1° 格网里占比 < 1%，直方图几乎不可能双峰，直接套 Otsu 会失效。必须先缩小候选域（常绿植被 × 坡度 × 产茶县等），再在候选域内做阈值；或者改用其他阈值方法 |
| 耕地图层掩膜 | 候选域掩膜（ESA 树木、灌丛、农田等） | ESA 2021 里茶园被标成什么类别，需要用复核点统计 |
| 3×3 空间滤波保证纯度 | 同样适用 | 台地茶田块窄、行间有过道。3×3（30 m）同质性要求可能删掉大量真实茶园，需要用探针点检验保留率 |
| 由易到难剥离：先林地，后油菜 | 先去掉非植被、落叶林、耕地，最后处理茶树与常绿林 | 茶树和常绿林是本项目的「小麦和油菜」，必须为它找到专门的敏感特征和时期 |
| refined Lee + 月度中值后再用 S1 | 我们已改用 3×3 均值降斑（单像元跳动从约 2.0 降到 1.4–1.6 dB） | 杨只把 S1 用在生物量差异很大的作物对（小麦与油菜）上；茶树与常绿林的结构差异小得多 |
| 回避不稳定物候窗口 | 「不依赖固定月份」的 TI 目标与此一致 | 修剪时间在不同茶区差异大，修剪信号只能用阶段内的局部极值或幅度来表达，不能用固定日期 |
| RF 能容忍 20% 标签噪声 | S3 样本纯度门槛 ≥ 95% 留有余量 | 但茶树是稀有类，误标的常绿林会直接拉低 UA，不能照搬 20% 的容忍度 |
| 潘荣玉：江苏五月修剪、固定阈值 | 相当于茶树版的 AGTOC，规则固定 | 正是本项目要用自适应阈值和 TI 突破的地方 |

## 5. 可借鉴的数据处理细节（细读补充，2026-11-16）

### 5.1 影像预处理：先做规则、连续的数据立方体，再谈特征

| 环节 | 杨的做法 | 出处 |
|---|---|---|
| S2 去云 | 云概率数据集逐像素掩膜（第二章用 QA60，且剔除云量 > 20% 的景） | p.22, p.49 |
| S2 时间合成 | **月度中值合成**：消除各地观测数量不一致的影响，规则时序也更高效 | p.21–22, p.49 |
| 缺测填补 | 两期以上缺失的像素约占 2%，**线性插值**补齐；第五章再加 MODIS 回归填补 + **Whittaker 平滑** | p.50, p.111 |
| S2 指数 | NDVI（绿度）、LSWI（水分，B8/B11）、NDRE（叶绿素，B6/B5），三个指数各代表一个维度；第二章还用了 EVI、GNDVI、CIRE 等 | p.23, p.50, p.82 |
| S1 | **只用升轨**（中国东部没有降轨）；**逐景 refined Lee 滤波**；VV、VH、VV−VH、VH/VV；月度中值；第五章改为 6 天间隔 + Whittaker 平滑 | p.50, p.111 |
| S1 与 S2 合用 | 把 VV、VH **归一化到 0–1**，避免量纲差异使特征权重偏向某一类 | p.82 |
| 与时间无关的时序特征 | **谐波回归**：n = 2，ω = 1.5，每个特征得到 5 个系数（截距 + 2 对 sin/cos），12 个特征共 60 个系数 | p.124 |
| 特征筛选 | JM 距离，每对类别取前 3 名，多对类别都排名靠前的特征优先；RF 的 GINI 重要性用于解释 | p.29–30, p.62 |

### 5.2 掩膜、格网与阈值

| 环节 | 杨的做法 | 出处 |
|---|---|---|
| 耕地掩膜 | **4 套产品（FROM_GLC10、GlobeLand30、GFSAD30、WorldCover）中至少 3 套认为是耕地**，才算耕地；山地丘陵区再用 WorldCover 剔除被误标为耕地的灌木 | p.85, p.114 |
| 分块计算 | SNIC 在 20 km 格网分块运行；WCI-Otsu 在 1° 格网；第五章的 RF 用 3×3 格网训练、预测中心格网（局部自适应 RF） | p.26, p.55, p.124 |
| Otsu 之前 | 先用 **IQR 规则**剔除指数的异常值：只保留 [Q1 − 1.5 IQR, Q3 + 1.5 IQR] 区间内的值 | p.92 |
| 补充先验规则 | Otsu 之后再加简单的农学规则（如 VHmax、NDVIva），排除「本区没有该类却被切出来」的情况 | p.92–93 |

### 5.3 样本与分类器

| 环节 | 杨的做法 | 出处 |
|---|---|---|
| 抽样 | 每个格网分层随机抽 1000 个像素 → 3×3 八邻域同类过滤 | p.59 |
| 参考数据 | 先随机抽 10,000 个 → 删除间距 < 1 km 的点（避免空间自相关）→ 删除置信度 < 90% 的点 → 空间滤波 | p.86 |
| RF | 100 棵树（超过 100 棵精度不再上升），每次分裂候选变量数取特征数的平方根；按省建模 | p.59 |
| 开发与检验分开 | 第四章 TR1–4 用于开发，TR5–7 只用于检验方法能否推广 | p.80 |

### 5.4 验证设计（可直接用于本项目 S5）

**两阶段分层抽样**（第五章，p.125–127）：
1. **第一阶段**：把研究区划成 0.1° 的正六边形格网，用已有产品（ChinaCP）算出每个格网的目标占比，分成高（> 50%）、中（30–50%）、低（< 30%）、极低四层，每层随机抽 25 个格网。
2. **第二阶段**：在抽中的格网里各随机抽 10 个像元，一共 1000 个点。这些点抽出来时只有位置，没有类别。
3. **判读**：先用 Google Earth 判断是作物还是非作物，再对照参考时序曲线；特征不明确的点删除。
4. 地面调查点也要做 3×3 同质过滤，距离太近的点只留一个。
5. **面积**：与省、市统计数据比较 R² 和 RMSE，**只作对照**；另外与已有产品做图对图的定性比较。

## 6. 对照本项目：方向上的偏差

| | 杨的做法 | 我们目前的做法 | 偏差 |
|---|---|---|---|
| 时序数据 | 月度中值合成、插值补齐、平滑后的规则序列 | 单景原始观测散点（S2 经过 CS+ 去云，S1 单像元，最近才改为 3×3） | 我们在原始观测上找信号，噪声大、各点观测数量不一，E03、E03c 的否定结果有一部分来自这里 |
| 地面点的用途 | 只用来看类别曲线（均值 ± 标准差）和做验证，数量不多 | 投入大量精力打探针点，并逐个特征做统计检验 | 探针点被当成了主角；杨的主角是全覆盖的指数图层 |
| 指数设计 | 先看各类别的均值曲线，用农学知识写出乘积指数，**直接在整幅影像上计算**，看直方图是不是双峰 | 一直在点上算单特征 AUC，还没有在整幅影像上算过任何茶树指数 | 没有尽早做「全覆盖 → 看直方图 → Otsu」这一步，最关键的风险（茶园稀少导致 Otsu 失效）也还没检验 |
| S1 | refined Lee + 月度中值 + 归一化；只用在差异最大的一对类别上 | 单像元 → 3×3 均值 | 方向一致，但没有用月度合成 |

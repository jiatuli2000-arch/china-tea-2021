# 01 精度目标与验收门槛

> 目标：**图要能看，精度要高**。精度只以独立验证点（S5）为准，不以训练集、探针点或年鉴代替。

## 1. 精度目标（以茶区为单位分别达标）

| 指标 | 目标 | 说明 |
|---|---|---|
| 茶园 F1 | ≥ 0.85 | 主指标 |
| 茶园用户精度 UA | ≥ 0.85 | 控制误报（林地误判为茶） |
| 茶园生产者精度 PA | ≥ 0.80 | 控制漏报 |
| 总体精度 OA | 报告，不作主指标 | 非茶类占绝对多数，OA 天然偏高 |
| 面积 | Olofsson 无偏估计 ± 95% CI | 与图上面积并列报告 |

> **定稿（2026-11-15）**。未达标时改进方法（回到 S2/S3/S4），**不降低门槛**。

## 2. 各阶段门槛

| 阶段 | 门槛 |
|---|---|
| S1 探针 | 每茶区每个主要类别 ≥ 50 个高置信、经 Google Earth 复核的点；华南不要求落叶林（`config/labels.yaml` 的 `s1_exempt`，2026-11-16 决定：安溪落叶林候选 22 个，标注后 0 个是落叶林） |
| S2 TI | TI 在每个茶区内，茶 vs 常绿林、竹林、果园均可分（指标与阈值在 S2 README 中预先登记） |
| S3 样本 | 每茶区随机抽检 ≥ 100 个自动样本，目视纯度 ≥ 95% |
| S4 制图 | 每茶区随机抽 ≥ 10 个 0.1° 网格目视检查：无明显椒盐噪声、无成片山林误报 |
| S5 验证 | 达到第 1 节目标 |

## 3. "图能看"的视觉标准

- 茶园斑块边界与高分影像地块吻合，无孤立像元噪声（最小制图单元在 S4 定义并单独成版）。
- 不出现整面山体被判为茶园的情况。
- 省界、格网接缝处无断裂或阶跃。

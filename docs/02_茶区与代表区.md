# 02 茶区与代表区（S1 探针范围）

## 四大茶区划分

沿用传统的四大茶区划分（江北、江南、华南、西南），引用：郑菲菲, 詹慧龙, 雷国铨, 等. 中国四大茶区三产融合时空分异特征及其影响因素[J]. 资源科学, 2024, 46(12): 2532-2545. DOI: 10.18402/resci.2024.12.14

本地边界 `data/raw/boundaries/tea_zones/`（按省整体归入茶区，CGCS2000）：

| 茶区 | 省份 |
|---|---|
| 江北 | 河南、陕西、甘肃、山东 |
| 江南 | 浙江、江苏、安徽、江西、湖北、湖南 |
| 华南 | 福建、广东、广西、海南、台湾 |
| 西南 | 云南、贵州、四川、重庆、西藏 |

> 注意：经典区划中苏北、皖北、鄂北属于江北茶区，本边界为简化做法，把它们整省归入了江南。在 S2 中需检查这种简化是否影响分区阈值；如有需要，再按地市细化。台湾省暂不纳入制图范围（缺少可比的统计数据），是否纳入待定。

## 代表区

| 茶区 | 代表区（候选） | 已有基础 |
|---|---|---|
| 江北 | 河南信阳 / 安徽六安 | 无 |
| 江南 | 苏南（基线区）、安徽黄山 | 江苏 GPS 点、潘荣玉 AGRFT 数据；黄山 2021 人工判读点 |
| 华南 | 福建安溪 | 无 |
| 西南 | 云南普洱或临沧 | 云南 GPS 点 |

- 苏南同时作为**对照基线区**：复现 AGRFT（潘荣玉，2026），与本研究 TI 方法对比。
- 旧项目数据仅作为原始输入迁入 `data/raw/`，须在 `ledger/data_manifest.csv` 登记出处。

# 00 研究定义与标注协议

> 状态：草稿（S0）。所有探针点、验证点的标注必须遵守本协议；协议修改需记录版本与日期。

## 1. 制图对象

**茶园（目标类）**：人工持续管理的、常绿、矮灌、成行种植的**常规台地茶**，且在 2021 年卫星影像上**地表以茶树冠层为主**。

| 情形 | 标注 | 理由 |
|---|---|---|
| 常规台地茶、梯田茶 | **茶园** | 目标 |
| 古茶山 / 古茶树（云南等） | 非目标（`ancient_tea`） | 乔木状、无规律修剪，不属于研究对象 |
| 林下茶、遮荫树明显覆盖的生态茶园 | 非目标（`shaded_tea`） | 卫星看不到茶树冠层 |
| 新垦未成园、已抛荒茶园 | 非目标（`other`） | 无持续管理信号 |

> 口径声明：本研究只统计**卫星可见**的台地茶面积，预期系统性低于统计年鉴面积。年鉴仅用于相关性与排名一致性检验，**禁止依据年鉴面积反调阈值**。

## 2. 标注类别

| 代码 | 类别 | 备注 |
|---|---|---|
| `tea` | 台地茶 | 目标 |
| `evergreen_forest` | 常绿林 | 最主要混淆类 |
| `bamboo` | 竹林 | 南方主要混淆类 |
| `deciduous_forest` | 落叶林 | |
| `orchard` | 果园（柑橘等常绿果园） | 混淆类 |
| `cropland` | 农田 | |
| `shrub_grass` | 自然灌丛 / 草地 | |
| `built` | 建筑 | |
| `water` | 水体 | |
| `ancient_tea` / `shaded_tea` | 古茶 / 林下茶 | 非目标，单独记录便于讨论 |

## 3. 两类人工点，严格分离

| | 探针点（probe） | 独立验证点（validation） |
|---|---|---|
| 用途 | 定义/检验茶树指数（TI）、生成样本的先验 | 精度评估与无偏面积估计 |
| 时间 | **制图之前** | **地图冻结之后** |
| 抽样 | 目的性选取，覆盖各类别 | 按地图类别**分层随机抽样** |
| 能否参与调参 | 可以 | **绝不** |

## 4. 标注记录字段

`point_id, lon, lat, label, confidence(1-3), imagery_source, imagery_date, zone, province, annotator, note`

- 置信度 1（不确定）的点不进入训练/验证，仅留存。
- 坐标为 WGS84 十进制度。

# S2 茶树指数（TI）构建与跨区可分性

**目的**：把茶园定义翻译为可测量信号，构建不依赖固定月份的茶树指数。

候选构成（[推测]，待本阶段检验）：

| 定义属性 | 候选信号 |
|---|---|
| 常绿 | 全年 NDVI 最小值 / 冬季与峰值之比 |
| 人工持续管理 | 生长季内最深一次 NDVI/纹理下凹幅度（不指定月份） |
| 矮灌 | 冠层高度产品；Sentinel-1 VH 体散射 |

候选形式：`TI = 常绿度 × 管理扰动幅度 × 矮度`

- 输入：S1 探针点；Sentinel-1/2 2021 时序（`year` 从 config 读取）
- 输出：各茶区各类时序曲线、单信号与 TI 可分性表、TI 定稿公式
- 验收：**在跑分析之前**于本文件登记可分性指标与通过阈值，之后不得修改

## 预实验 E01：Sentinel-2 地形校正对比（2026-11-15 登记，运行前写定）

> 偏离说明：S1 整体验收尚未通过（另外三个茶区还没有点），本实验只用江南（黄山）探针点做**方法预研**，结论不冻结，等四个茶区齐了再复验。

**问题**：阴坡 NDVI 偏低（冬季更明显），是否需要对 Sentinel-2 做地形校正？

**数据**：`data/raw/probes/jiangnan__huangshan*.csv` 中置信度 ≥ 2 的茶树、非茶常绿林、落叶林、常绿落叶混交林、耕地（不含混合像元、建筑）；2021 年 S2 SR 单景观测，Cloud Score+ ≥ 0.6。

**校正方法**：SCS+C（Soenen et al., 2005）。逐景计算太阳入射角余弦 cos i（Copernicus GLO-30 DEM 坡度坡向 + 景元数据太阳天顶角/方位角）；C 由该景黄山境内 ESA 树木像元的「波段反射率 ~ cos i」线性回归得到（C = 截距/斜率）。cos i ≤ 0.1 的观测不做校正，单独计数。

**特征**（每点，校正前/后各一套）：冬季 NDVI 中位数（1–2 月、12 月）、夏季 NDVI 中位数（6–8 月）、全年 NDVI 第 10 / 90 百分位。

**评价指标**：
1. **光照依赖**：每类内，冬季 NDVI 与冬季平均 cos i 的 Spearman 相关系数 ρ。
2. **可分性**：单特征 AUC（取 max(AUC, 1−AUC)），类别对：茶–常绿林、茶–落叶林、常绿林–落叶林；全部点，以及按冬季 cos i 中位数分的阴坡组、阳坡组。

**采用规则**（满足全部三条才采用校正）：
- (a) 茶树、常绿林两类的 |ρ| 都下降；
- (b) 阴坡组中，至少一个类别对的至少一个特征 AUC 提高 ≥ 0.02；
- (c) 全部点上，所有「茶–其他」类别对的所有特征，AUC 下降都不超过 0.02。

结果写入 `stages/S2_tea_index/E01_terrain_correction.md`。

### E01 偏离记录（2026-11-15，运行中发现）

逐景回归时，L2A 地表反射率与 cos i 的关系接近 0，甚至为负。用同一景的 L1C 大气顶层反射率对照（黄山境内的 ESA 树木像元，hillshade 作光照指标，[已验证]，4 景）：

| 景 | L1C 的 NDVI 斜率 | L2A 的 NDVI 斜率 |
|---|---|---|
| 2021-09-23 | +0.155 | +0.005 |
| 2021-11-27 | +0.335 | −0.005 |
| 2021-12-02 | +0.368 | −0.052 |
| 2021-12-27 | +0.405 | +0.072 |

说明 `S2_SR_HARMONIZED`（Sen2Cor L2A）**已经做过地形校正**。在它上面再做 SCS+C 属于重复校正，原设计不成立。**实际做法改为**：检验 L2A 的**残留**地形影响，按原预登记指标 1 和 2 只计算「L2A 原值」，不再生成 SCS+C 校正值。判定：若茶树、常绿林冬季 NDVI 与 cos i 的 |ρ| < 0.2，且阴坡组和阳坡组的 AUC 差异 < 0.05，则不做额外校正。（这条判定规则是发现问题后新定的，不属于原预登记。）

## 预实验 E01b：残留地形影响的置信区间与经验校正（2026-11-15 登记，运行前写定）

**问题**：E01 看到的残留（冬季 NDVI 与 cos i 相关 ρ ≈ +0.2 到 +0.3，阴坡和阳坡 AUC 最多差 0.112）是真实效应还是抽样噪声？用一个简单的经验校正能不能消除它？

**数据**：与 E01 相同（江南·黄山探针点，S2 L2A 观测）。

**经验校正**（参数只从**未标注像元**估计，不用探针点，避免循环论证）：
- 逐景在黄山境内随机抽 ESA 树木像元（30 m，3000 个，无云），回归 NDVI ~ cos i，得斜率 β。
- 每条观测：NDVI′ = NDVI − β ×（cos i − cos θz），θz 为太阳天顶角，即把每个像元换算到「平地」光照。
- 有效像元 ≥ 300 的景用自己的 β；其他景用同月可靠景 β 的中位数，再没有就用全年中位数。

**统计**：bootstrap 2000 次（按类别、阴阳坡分层重抽点），给出 95% 置信区间：
1. 茶树、常绿林的 ρ（冬季 NDVI 与冬季 cos i）；
2. 各类别对 × 各特征的 AUC 阴阳坡差（阴 − 阳）；
3. 全部点上「茶–其他」各类别对、各特征的 AUC。

**判读**：
- 残留是否真实：看原值的 ρ 和 AUC 阴阳坡差，95% 置信区间是否不含 0。
- **采用经验校正的条件**（全部满足）：(i) 茶树、常绿林的 \|ρ\| 都下降至少 0.05；(ii) 全部点上茶–其他各项 AUC 下降不超过 0.02；(iii) AUC 阴阳坡差的置信区间不含 0 的项数没有增加。

结果写入 `stages/S2_tea_index/E01b_residual_terrain.md`。

### E01 / E01b 小结（2026-11-15，仅江南·黄山）

- Sentinel-2 L2A 已由 Sen2Cor 做过地形校正 [已验证]；**不再做额外的地形校正**（E01b 预登记规则 (i) 不满足）。
- 冬季 NDVI 与光照的正相关在点上显著（茶树 ρ = +0.19，常绿林 +0.29），但用未标注树木像元估计的逐景斜率中位数为 −0.024，方向相反；这种相关更可能来自坡向与植被状况的关联，而不是光照本身 [推测]。
- 关键：阴坡和阳坡之间**可分性没有显著差异**（12 项 AUC 差的 95% 置信区间全部包含 0）；E01 看到的 0.112 属于抽样噪声。
- 待办：四个茶区的探针点齐了以后复验；Sentinel-1 的地形平坦化另做实验。

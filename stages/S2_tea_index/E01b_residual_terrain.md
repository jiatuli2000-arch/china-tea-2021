## 4. 判读

- 残留是否真实：ρ 置信区间不含 0 → 茶树 是、常绿林 是；AUC 阴阳坡差置信区间不含 0 的项：0 / 12。

| 采用经验校正的条件 | 结果 |
|---|---|
| (i) 茶树、常绿林的 \|ρ\| 都下降 ≥ 0.05 | 不满足 |
| (ii) 茶–其他各项 AUC 下降 ≤ 0.02 | 满足（最大变化 -0.005） |
| (iii) 阴阳坡差显著项数没有增加 | 满足（0 → 0） |

**结论：不采用经验地形校正**；残留效应在统计上真实存在。只基于江南·黄山。

# E01 Sentinel-2 地形影响检验 · 结果

> 数据：`data/interim/S2/e01_*.csv`，S2 L2A（`S2_SR_HARMONIZED`），14594 条无云观测（Cloud Score+ ≥ 0.6）。冬季 = 1–2 月和 12 月。阴坡、阳坡按冬季平均 cos i 的中位数 0.575 划分。原设计为什么改、判定规则怎么来的，见 README「E01 偏离记录」。

## 0. 起因：L2A 已做地形校正 [已验证]

同一景影像，黄山境内树木像元的 NDVI 对 hillshade 的回归斜率，L1C 为 +0.155 至 +0.405，L2A 为 −0.052 至 +0.072（4 景，见 README）。

## 1. 残留光照依赖：冬季 NDVI 与冬季 cos i 的 Spearman ρ

| 类别 | 点数 | ρ | 冬季 NDVI 中位数（阴坡 / 阳坡） |
|---|---|---|---|
| 茶树 | 145（阴 91） | +0.186 | 0.767 / 0.786 |
| 常绿林 | 165（阴 76） | +0.292 | 0.761 / 0.795 |
| 落叶林 | 55（阴 28） | -0.154 | 0.455 / 0.437 |
| 耕地 | 63（阴 15） | +0.058 | 0.345 / 0.389 |

## 2. 可分性：单特征 AUC（全部 / 阴坡 / 阳坡）

|---|---|---|---|---|
| 茶树–常绿林 | 0.515 / 0.544 / 0.545 | 0.904 / 0.896 / 0.911 | 0.665 / 0.592 / 0.695 | 0.525 / 0.575 / 0.545 |
| 茶树–落叶林 | 0.955 / 0.961 / 0.930 | 0.943 / 0.925 / 0.968 | 0.933 / 0.943 / 0.922 | 0.580 / 0.616 / 0.504 |
| 常绿林–落叶林 | 0.985 / 0.971 / 0.993 | 0.564 / 0.547 / 0.589 | 0.979 / 0.963 / 0.993 | 0.588 / 0.612 / 0.567 |

## 3. 判定

| 条件 | 结果 |
|---|---|
| 茶树、常绿林的 \|ρ\| < 0.2 | 不满足 |
| 阴坡与阳坡的 AUC 差异 < 0.05 | 不满足（最大差异 0.112） |

**结论：存在不可忽略的残留地形影响，需要进一步处理**。只基于江南·黄山的数据，四个茶区齐了以后复验。
